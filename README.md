# Telegram Mini App Production Starter

Production-oriented React and FastAPI foundation for Telegram Mini Apps with server-validated init data, PostgreSQL, Docker, automated tests, and an adaptive mobile interface.

> The repository is under active initial development on a dedicated build branch. The complete verified quick start is published with v0.1.0.

This project is independent and is not affiliated with, endorsed by, or sponsored by Telegram.
