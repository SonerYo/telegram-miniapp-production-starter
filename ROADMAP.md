# Roadmap

No dates are promised. Priorities follow real maintainer capacity and user feedback.

## v0.1.0

- Full-stack React and FastAPI monorepo.
- Official Telegram bridge adapter and browser mock mode.
- Server-side init data validation and verified user upsert.
- Owner-scoped task CRUD and adaptive demo UI.
- PostgreSQL, Alembic, Docker, Nginx, CI, security automation, and OSS documentation.

## Near term

- Verify clean install across macOS, Linux, and Windows documentation paths.
- Add localization architecture and one second locale.
- Expand accessibility and real Telegram client smoke-test recipes.
- Add another deployment guide based on actual maintainer use.
- Document optional shared Redis rate limiting.
- Add OpenTelemetry and error-reporting recipes without required vendor credentials.
- Consider Storybook when component maintenance justifies its cost.

## Later

- Telegram MainButton and BackButton recipe collection.
- Payments and Stars as separately threat-modeled examples.
- Notification patterns and background processing guidance.
- Reusable UI package extraction after multiple consumers validate the API.
- Additional managed database and edge deployment targets.

## Explicitly not planned for the core starter

- Product-specific analytics, AI, social feeds, or business workflows.
- A built-in Kubernetes or Terraform opinion for every deployment.
- A default admin panel or complex RBAC.
- Redis, queues, or WebSockets without a demonstrated starter use case.
- Claims of official Telegram or OpenAI affiliation.
